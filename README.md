# MWAMBE Agency Website & CMS

PHP 8.1+ / MySQL 8 / vanilla MVC. Hosted on shared cPanel.

## Requirements
- PHP 8.1 or higher (cPanel → MultiPHP Manager)
- MySQL 5.7+ or MariaDB 10.3+
- Composer 2.x (locally, or via cPanel Terminal if available)
- PHP extensions: pdo_mysql, mbstring, json, fileinfo, openssl, curl
